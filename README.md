# Gamified Blog System

A full-stack blogging platform integrating gamification mechanics to increase user engagement through rewards, progression systems, and interactive challenges.

## 🚀 Overview

The platform combines content publishing with game-inspired engagement features such as XP progression, leaderboards, and achievement systems.

Designed with scalable backend APIs and structured data modeling.

## ✨ Features

- Secure authentication
- Blog creation and management
- XP and level progression
- Achievement badges
- Leaderboards and ranking logic
- Daily challenges
- User profiles and activity tracking

## 🏗 Tech Stack

**Backend**
- Node.js / Flask (based on implementation)
- REST APIs
- MongoDB

**Frontend**
- React
- Tailwind CSS

## 🧠 Engineering Highlights

- Gamification logic engine
- Reward tracking system
- Scalable content APIs
- Leaderboard ranking algorithms
